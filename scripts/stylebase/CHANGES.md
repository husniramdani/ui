## Changes from UI SDK

This fork changes these files of [UI SDK](https://github.com/vercel-labs/ui) (Apache-2.0). Each change has an issue on the fork with the problem, before and after evidence, and the fix.

Based on UI SDK 0.1.0-beta.7. Two earlier changes were dropped because upstream fixed them in that release: the combobox caret jumping to the end ([#1](https://github.com/husniramdani/ui/issues/1), upstream [#663](https://github.com/vercel-labs/ui/pull/663)) and a combobox's label click opening the list ([#9](https://github.com/husniramdani/ui/issues/9), upstream [#684](https://github.com/vercel-labs/ui/pull/684)).

- **A combobox's list was named by the text in its input, not by its label** ([#2](https://github.com/husniramdani/ui/issues/2), upstream [vercel-labs/ui#572](https://github.com/vercel-labs/ui/issues/572)). Changed: `packages/core/src/foundation/lists/listbox-popup.ts`.
- **New combobox option `highlightSelected`**: opening the list highlights the selected item ([#5](https://github.com/husniramdani/ui/issues/5)). Changed: `packages/core/src/components/combobox/combobox.ts`, `packages/core/src/components/combobox/combobox-api.ts`, `packages/svelte/src/combobox/combobox.svelte`, `packages/vue/src/combobox.ts`, and each framework's combobox docs page (`docs/components/combobox.md` in the React, Vue and Svelte packages).
- **New dialog content option `inline`**: a contained dialog renders in place, in the page's flow, instead of in the top layer ([#7](https://github.com/husniramdani/ui/issues/7), upstream proposal [vercel-labs/ui#681](https://github.com/vercel-labs/ui/issues/681)). Changed: `packages/core/src/components/dialog/dialog.ts`, `packages/core/src/components/dialog/dialog-parts.ts`, `packages/core/src/components/drawer/drawer.ts`, `packages/core/src/foundation/popups/popup.ts`, `packages/core/src/foundation/popups/popup-slots.ts`, `packages/react/src/dialog-parts.tsx`, `packages/vue/src/dialog-parts.ts`, `packages/svelte/src/dialog/dialog-content.svelte`, `packages/solid/src/dialog-parts.tsx`, `packages/web/src/events.ts`, and each framework's dialog docs page.
- **A popup placed again from between two layout steps landed a fraction of a pixel off** ([#11](https://github.com/husniramdani/ui/issues/11), upstream [vercel-labs/ui#700](https://github.com/vercel-labs/ui/issues/700)). Changed: `packages/core/src/foundation/platform/position.ts`.
- **A Svelte menu with one-way `open` and content rendered only while open never opened again** ([#13](https://github.com/husniramdani/ui/issues/13), upstream [vercel-labs/ui#776](https://github.com/vercel-labs/ui/issues/776)). Changed: `packages/svelte/src/use-primitive.svelte.ts`.
- **New select option `virtualFocus`**: focus stays on the trigger while the list is open, which points at the highlighted option with `aria-activedescendant`, as on a native select ([#15](https://github.com/husniramdani/ui/issues/15), upstream proposal [vercel-labs/ui#784](https://github.com/vercel-labs/ui/issues/784)). Changed: `packages/core/src/components/select/select.ts`, `packages/core/src/components/select/select-api.ts`, `packages/core/src/components/select/select-parts.ts`, `packages/core/src/components/select/select-keyboard.ts`, `packages/vue/src/select.ts`, `packages/svelte/src/select/select.svelte`, and each framework's select docs page.
- **A controlled OTP input moved the caret to the end after a character was deleted or typed mid-code**, so the next character went after the code, and also when its owner changed the edit, like into capitals ([#17](https://github.com/husniramdani/ui/issues/17), upstream [vercel-labs/ui#787](https://github.com/vercel-labs/ui/issues/787)). Changed: `packages/core/src/components/otp-input/otp-input-api.ts`.
- **New listbox option `virtualFocus`**: focus stays on the listbox, which points at the highlighted option with `aria-activedescendant`, instead of moving onto the options ([#20](https://github.com/husniramdani/ui/issues/20), upstream proposal [vercel-labs/ui#790](https://github.com/vercel-labs/ui/issues/790)). Changed: `packages/core/src/components/listbox/listbox-root.ts`, `packages/core/src/components/listbox/listbox-root-api.ts`, `packages/core/src/components/listbox/listbox-root-parts.ts`, `packages/core/src/components/listbox/listbox-root-keyboard.ts`, `packages/react/src/listbox.tsx`, `packages/vue/src/listbox.ts`, `packages/svelte/src/listbox/listbox.svelte`, `packages/solid/src/listbox.tsx`, and each framework's listbox docs page.
- **An exit animation wiped the `inert` an element's owner wrote while it closed**, so a collapsible panel kept mounted and inert while closed had its body back in the Tab order ([#23](https://github.com/husniramdani/ui/issues/23), upstream [vercel-labs/ui#804](https://github.com/vercel-labs/ui/issues/804)). Changed: `packages/core/src/foundation/motion/presence.ts`.
